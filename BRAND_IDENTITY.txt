──────────────────────────────────────────────────────────────────────
5. FARBSYSTEM  ("Minimal Luxury Clay")
──────────────────────────────────────────────────────────────────────
Eine einzige warme Leinwand. Elemente werden wie aus Ton "herausge-
stanzt" — ruhig, taktil, zurückhaltend. Kein reines Schwarz, kein
Neon, keine harten Schlagschatten.

Kern:
  --paper        #F5F1EA   Warmes Galerie-Ivory (Haupt-Hintergrund)
  --paper-deep   #EDE8DD   Sektionswechsel (hell)
  --paper-dark   #E3DDCF   Sektionstrenner / Vertiefung
  --ink          #26241F   Weicher, warmer Fast-Schwarz-Text
  --ink-soft     rgba(38,36,31,0.60)  Sekundärtext
  --ink-faint    rgba(38,36,31,0.34)  Tertiärtext / Labels

Marken-Akzente:
  --stone        #A9A093   Neutraler Stein (Flächen, Icons)
  --god          #BA986A   Gold-Akzent (Licht, Highlights)
  --god-deep     #9A7A50   Gold dunkel (Hover, Linien)
  --olive        #525240   Olive (dunkle Sektionen, Kontrast)
  --olive-deep   #3D3C32   Olive tief (Footer, Flächen)

Schatten (Clay):
  Clay-Tönung:   rgba(118,102,79, …)  — warmes Sepia, nie #000
  --clay-soft:   0 20px 44px -16px rgba(118,102,79,0.22)   (Container)
  --clay-float:   0 2px 3px rgba(255,255,255,0.55),
                  0 28px 60px -24px rgba(118,102,79,0.32) (schwebend)

  REGEL: Der volle dreistufige Clay-Schatten ist NUR für interaktive
  Elemente (Buttons, Showcase-Gerät) reserviert. Container bekommen
  nur einen sanften Float. Licht kommt immer von oben links.

  Stanz-Technik: Text/Form in Hintergrundfarbe füllen + textShadow,
  damit er wie aus der Fläche geschnitten wirkt.

──────────────────────────────────────────────────────────────────────
6. TYPOGRAFIE
──────────────────────────────────────────────────────────────────────
Display / Headlines:  Playfair Display (Serif)
                      Gewichte 400/500/600, kursiv für Betonung
                      letter-spacing: -0.01em
                      → elegant, editorial, "Luxus"

Fließtext / UI:       Montserrat (Sans-Serif)
                      Gewichte 300/400/500/600
                      → klar, modern, warm

Labels / Nav / Meta:  Montserrat, Versalien, gesperrt (tracking),
                      klein (11–13px), oft in --ink-faint oder Gold.

Fallbacks:            Georgia (Serif), system-ui (Sans)

Hierarchie: Ruhig und großzügig. Wenige Größen, viel Weißraum,
klare Kontraste. Keine fetten System-Fonts, kein Mix vieler Schriften.

──────────────────────────────────────────────────────────────────────
7. DESIGN-PRINZIPIEN
──────────────────────────────────────────────────────────────────────
1. Eine Leinwand.      Warmes Ivory als Basis; Sektionen wechseln
                       zwischen Papier (hell) und Olive (dunkel).
2. Wenig, aber präzise. Reduktion statt Dekoration.
3. Taktil & leise.     Clay-Textur, weiche Schatten, keine grellen
                       Effekte, keine harten Kanten-Schatten.
4. Bedeutung zeigen.   Jede App/jedes Projekt hat eine Story
                       ("Built with meaning").
5. Licht von links oben.
6. Konsistenz.         Gleiche Tokens über alle Seiten & Apps;
                       pro App eigene Palette, aber gleiches System
                       (Typo, Rhythmus, Schattenlogik).

11. DO & DON'T
──────────────────────────────────────────────────────────────────────
DO:
  + Marke immer "Elior" schreiben, Domain immer elior.studio.
  + Tokens aus dem Farbsystem verwenden.
  + Playfair für Display, Montserrat für Text.
  + Weißraum großzügig, Kontraste ruhig.
  + Ehrliche, prüfbare Angaben (NAP konsistent).

DON'T:
  - "AWEN28"/"Awenya" als aktive Marke nennen (nur als Historie).
  - Parallele Domains verlinken.
  - Reines Schwarz, kalte Schatten, Neon-Farben.
  - Logo verzerren/einfärben/Effekte geben.
  - Erfundene Ratings/Superlative in strukturierten Daten.
